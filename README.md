# בית ההמפ בצוקים: אתר האורחים

## מה יש בתיקייה
- `index.html`: האתר השיווקי בעברית (stay.shushka.co.il)
- `en/index.html`: האתר השיווקי באנגלית (stay.shushka.co.il/en/)
- `guide/index.html`: מדריך האורחים, נשלח רק למי שהזמין (stay.shushka.co.il/guide/#house או #studio)
- `assets/`: עיצוב (`site.css`), תמונות (`images/`)
- `CNAME`: אומר לגיטהאב שהכתובת היא stay.shushka.co.il

## לפני שמעלים: למלא את הסימונים הצהובים
חפשו `class="todo"`. שם יש לכם דברים שרק אתם יודעים: Wi-Fi, איפה המפתח, חנייה, ממ"ד, מרפאה קרובה, פחי זבל, מטף, קישור לסרטון הטאבון.

> האתר ציבורי (כל מי שיש לו את הקישור יכול לראות). הוספנו `noindex` כדי שגוגל לא יאנדקס אותו, אבל **לא לשים קודים של דלת/כספת**. את אלה שולחים בהודעה האישית ביום ההגעה.

## אחסון: GitHub Pages + stay.shushka.co.il
1. ב־GitHub: Settings → Pages → Source: `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`.
2. אצל מי שמנהל את ה־DNS של shushka.co.il מוסיפים רשומה:
   `CNAME` · שם: `stay` · ערך: `abokish.github.io`
3. חוזרים ל־Settings → Pages, מחכים שהדומיין יאומת, ומסמנים `Enforce HTTPS`.
החנות ב־shushka.co.il לא מושפעת מזה בכלל.

## אחסון חלופי

### 1. Netlify Drop: הכי פשוט, בלי ידע טכני
1. נכנסים ל־https://app.netlify.com/drop
2. גוררים את כל התיקייה `zuqim-site`.
3. מקבלים כתובת כמו `zuqim-hemp.netlify.app` (אפשר לשנות שם ב־Site settings).
4. עדכון: גוררים שוב את התיקייה (Deploys → drag and drop).

### 2. GitHub Pages: חינם לגמרי, גרסאות, וגם אני יכול לעדכן לכם
1. פותחים חשבון ב־github.com ויוצרים repository ציבורי, למשל `zuqim`.
2. Add file → Upload files → מעלים את תוכן התיקייה.
3. Settings → Pages → Source: `main` / root → Save.
4. הכתובת: `https://<שם-משתמש>.github.io/zuqim/`

### 3. Cloudflare Pages
כמו Netlify (גם אפשר לגרור תיקייה), עם רשת מהירה מאוד בישראל. https://pages.cloudflare.com

**דומיין משלכם (לא חובה):** כ־50 ₪ לשנה, למשל `zuqim-hemp.co.il`, ומחברים לכל אחת מהאפשרויות למעלה.
